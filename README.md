## 👩‍💻 About Me

I'm a **BCA Honours (4th Year)** student at **Gujarat University**, based in Ahmedabad, India, working toward becoming an **AI Engineer & Backend Developer**. My focus right now is on building real, working systems — not just tutorials — with **Python, FastAPI, and Next.js**, and increasingly with AI components like retrieval-augmented generation and vector search.

I'm currently building **production-quality AI applications**, the most significant being **MemoryVerse AI**, a document-intelligence system combining knowledge graphs, vector search, and RAG. Outside of that, I've shipped several full-stack Django and Next.js projects solving practical, real-world problems.

I'm still early in my journey and I'm upfront about that — but I learn by building, and I'm looking to keep growing through **open source, backend engineering, and applied AI**.

## 🚀 Featured Projects

### 🧠 [MemoryVerse AI](https://github.com/misbahsaiyed20/memoryverse-ai) — AI-Powered Digital Identity System
Turns scattered academic and professional documents (certificates, resumes, project reports) into a searchable, intelligent knowledge base using AI, knowledge graphs, vector search, and RAG.
- **Tech:** FastAPI, Next.js, PostgreSQL, ChromaDB, Google Gemini API, Firebase Auth
- **Highlights:** Document ingestion & chunking, entity/relationship extraction into a knowledge graph, semantic search over embeddings, and a "Verse AI" assistant that answers questions grounded in your own documents via RAG
- **Why it's interesting:** My most ambitious project — an end-to-end AI system covering ingestion, knowledge graphs, vector retrieval, and RAG, built for the MemoryVerse AI '26 Hackathon

### 🌾 [Seed2Sell](https://github.com/misbahsaiyed20/Seed2Sell) — E-Farming Platform
A Django web application connecting farmers directly with buyers.
- **Tech:** Django, Python, HTML, CSS, JavaScript
- **Highlights:** Farmer registration, product uploads, buyer orders, admin dashboard, secure payments, order tracking
- **Why it's interesting:** A complete, end-to-end marketplace flow solving a real problem for agricultural communities

### 🛠️ [FixMyArea](https://github.com/misbahsaiyed20/FixMyArea) — Civic Issue Reporting Platform
A Django platform for citizens to report local issues like potholes, garbage, and water leakage.
- **Tech:** Django, Python
- **Highlights:** Authentication, image uploads, duplicate report detection, interactive map, report tracking
- **Why it's interesting:** Combines geolocation and media handling into a genuinely usable civic tool

### 📄 [Webpage Summarizer](https://github.com/misbahsaiyed20/webpage-summarizer) — AI Browser Extension
A browser extension + Python backend that summarizes web pages using the Google Gemini API.
- **Tech:** Python, Gemini API, Browser Extension (JS)
- **Highlights:** Extension-to-backend architecture, real-time AI summarization
- **Why it's interesting:** My first hands-on project wiring an LLM API into an everyday browser tool

### 🎙️ [Voice Memo App](https://github.com/misbahsaiyed20/voice-memo-app) — Full-Stack Voice Notes App
A voice memo app with a Next.js/TypeScript frontend and a dedicated backend service.
- **Tech:** Next.js, TypeScript, React
- **Highlights:** Modern component-based frontend paired with a separate backend layer
- **Why it's interesting:** Reflects my move toward modern, type-safe frontend engineering

### 📝 [README Generator](https://github.com/misbahsaiyed20/readme-generator)
A JavaScript tool for generating developer README files.
- **Tech:** JavaScript
- **Why it's interesting:** A small developer-experience project focused on speeding up documentation
