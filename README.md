## 👨‍💻 About Me

I'm a Software Developer specializing in **Python, Django, and backend development**, currently building **AI-integrated web applications**. I'm associated with **Amin Softtech** and studied at **Gujarat University**, based in the Greater Ahmedabad Area.

My projects tackle practical, socially useful problems — from connecting farmers directly with buyers to helping citizens report civic issues in their neighborhoods. I'm also expanding into **AI/ML**, building tools that integrate LLM APIs (like Google Gemini) into everyday workflows, such as summarizing web pages directly from the browser. I enjoy full-stack development end-to-end: designing the backend, building the UI, and gluing it all together into something people can actually use.

## 🚀 Featured Projects

### 🌾 [Seed2Sell](https://github.com/misbahsaiyed20/Seed2Sell) — E-Farming Platform
A Django web application that connects farmers directly with buyers, cutting out unnecessary middlemen.
- **Tech:** Django, Python, HTML, CSS, JavaScript
- **Highlights:** Farmer registration, product uploads, buyer order system, admin dashboard, secure payments, and order tracking
- **Why it's interesting:** Solves a genuine real-world problem for agricultural communities with a complete, end-to-end marketplace flow

### 🛠️ [FixMyArea](https://github.com/misbahsaiyed20/FixMyArea) — Civic Issue Reporting Platform
A Django-based platform where citizens can report local issues like potholes, garbage, water leakage, and electricity faults.
- **Tech:** Django, Python
- **Highlights:** User authentication, image uploads, duplicate report detection, interactive map, and report tracking
- **Why it's interesting:** Combines geolocation, media handling, and deduplication logic to make civic reporting genuinely usable

### 🧠 [Webpage Summarizer](https://github.com/misbahsaiyed20/webpage-summarizer) — AI Browser Extension
A browser extension paired with a Python backend that uses the **Google Gemini API** to summarize web pages on demand.
- **Tech:** Python, Gemini API, Browser Extension (JS)
- **Highlights:** Extension + backend architecture, real-time AI summarization
- **Why it's interesting:** A hands-on project integrating an LLM API into a practical, everyday browser tool

### 🎙️ [Voice Memo App](https://github.com/misbahsaiyed20/voice-memo-app) — Full-Stack Voice Notes App
A voice memo application built with a Next.js/TypeScript frontend and a dedicated backend service.
- **Tech:** Next.js, TypeScript, React
- **Highlights:** Modern component-based frontend architecture with a separate backend layer
- **Why it's interesting:** Reflects a move toward modern, type-safe frontend engineering alongside a Django backend background

### 📝 [README Generator](https://github.com/misbahsaiyed20/readme-generator)
A JavaScript-based tool for generating developer README files.
- **Tech:** JavaScript
- **Why it's interesting:** A developer-experience project focused on making project documentation faster to produce
